Автокорректор (AutoCorrect) v1.0.4.2

Программа для Windows, которая сама ставит точки, запятые и заглавные буквы и исправляет орфографию прямо во время набора текста в любой программе.

Горячие клавиши:
- Ctrl+Alt+Пробел — включить / выключить
- Ctrl+Alt+C — исправить выделенный текст
- Ctrl+Z в течение 5 секунд — отменить последнюю правку

Как запустить: скачай AutoCorrect-v1.0.4.2.exe и запусти. Значок появится в трее.

Важно:
- exe без цифровой подписи. Если Windows SmartScreen предупредит — нажми «Подробнее» → «Выполнить в любом случае».
- Программа слушает клавиатуру только локально на твоём компьютере и ничего не отправляет в сеть.

Известное: вопрос без вопросительного слова (например «ты придёшь») получает точку, а не «?».
